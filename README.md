# ニューラルネットワーク手動学習体験アプリ

100～150名が一つの全結合ニューラルネットワークを共有し、各自に割り当てられた接続重みを操作する授業用Webアプリです。MNISTの数字 `1, 4, 7, 0` を28×28から6×6へ縮小し、36入力・4出力で学習します。中間層は教員が1層または2層、各3～5ニューロンで設定できます。

## 準備

Node.js 20以上を使用します。追加のnpmパッケージは不要です。初回のみ、ネットワークに接続できる環境で以下を実行します。

```powershell
node scripts/prepare-mnist.js
```

このスクリプトはMNISTの学習用画像とラベルをダウンロードし、対象4数字の全学習画像を6×6へ変換します。学生向けには各数字25件ずつ、計100件の28×28元画像・6×6画像・ラベルを生成します。生成物は`data/`に保存され、Gitには含まれません。再実行時はダウンロード済みの圧縮ファイルを利用します。

## 起動

```powershell
node server.js
```

- 教員画面：<http://localhost:8880>
- 学生画面：`http://<サーバのIPアドレス>/`（80番ポート）

教員画面右上の「学生向け情報を表示」を押すと、学生用URLとQRコードが開きます。ネットワークアドレスが複数ある場合は接続先を選べます。QRコードは同梱のMITライセンスの[qrcode-generator](https://www.npmjs.com/package/qrcode-generator)でブラウザ内生成し、外部のQRサービスへURLを送信しません。

教員ポートは`127.0.0.1`だけで待ち受けます。学生ポートはすべてのインターフェースで待ち受けます。必要に応じて環境変数`STUDENT_PORT`、`STUDENT_HOST`、`TEACHER_PORT`で変更できます。教室内から学生画面へ接続するには、サーバ側のファイアウォールで学生用ポートを許可してください。

教員画面で構成を設定した後、学生が参加します。参加中に構成を変更すると、確認後に重みと割り当てを初期化します。重みが不足すると構成確定前に中間層を最大5個まで増やします。教員の「構成を確定」で以後の自動拡張を止めます。観察用画像で常に暗い入力画素につながる重みは、学生へ割り当てません。

## 操作

学生は担当重みを手動スライダーで調整するか、自動モードにできます。スライダーの変更は直ちにサーバへ送られます。他の重みは自動取得ONなら2秒ごとに取得し、OFFでも「1回だけ取得」で取得できます。教員の固定画像やモード変更は重みの取得設定に関係なく1.5秒ごとに確認します。

学生画面上部の「使い方・説明書」から、アプリの目的、実際のMNIST画像を使った図、画面の見方、操作手順をページ内ウィンドウで確認できます。

画像の自動送りをONにすると2秒ごとに次の画像へ進み、100枚目の次は1枚目に戻ります。OFFでは前へ・次へ・一覧から画像を選び、そのまま表示できます。教員が画像を固定している間は自動送りを一時停止します。ON／OFF設定は左右に動くトグルで表示します。

PC画面では「ネットワークの状態」と「数字を見て予測する」を横並びにし、両方を見比べられます。出力ニューロンの右には対応する数字を`1・4・7・0`の順で表示します。

教員の「サーバの自動学習」がONなら、100msごとに32件のミニバッチでバックプロパゲーションを実行します。対象は自動モードの担当重み、未割り当て重み、バイアスです。手動モードの担当重みは更新しません。「全員を自動にして固定」を押すと、教員が解除するまで学生はモードを変更できません。

観察用100件は最初に一度取得し、同じタブではセッションストレージから再利用します。サーバの自動学習は対象4数字の全学習画像を使い、残りの画像は学生へ配布しません。状態はサーバのメモリに保持されるため、サーバ再起動で授業状態は初期化されます。
